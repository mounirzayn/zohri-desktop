# Zohri IPTV pour ordinateur

Application Windows et Mac de Zohri IPTV : une fenêtre qui charge l'app Zohri depuis son serveur, pour des mises à jour automatiques.

Téléchargement : https://tivora-api.onrender.com/telecharger

Zohri est un lecteur multimédia. Aucune chaîne ni aucun contenu n'est fourni.
